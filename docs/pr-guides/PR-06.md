Upstream worker example:

```python
async def run_job(job_id: str) -> None:
    notification = EmailNotification(
        to=(Recipient("ops@contoso.com"),),
        subject=f"Job {job_id} failed",
        text="Inspect the task logs for details.",
        idempotency_key=f"job-failed:{job_id}",
        source_application="task-runner",
    )
    result = await notification_client.send(notification)
    if result.state.value == "unknown":
        raise RuntimeError("Email acceptance is unknown; do not create a new key")
```

Release gates are environment-dependent: Power Automate trigger authentication,
flow ownership/co-ownership, shared-mailbox sending, internal-only enforcement,
attachment behavior, duplicate prevention when a flow response is lost,
webhook rotation, and shutdown during a provider call. Automated tests must
continue to use fakes. Graph authorization is a later optional-provider gate.
