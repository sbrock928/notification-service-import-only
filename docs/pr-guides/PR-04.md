Required test cases:

- A successful provider result maps to `DeliveryState.ACCEPTED`.
- A retryable, known-not-accepted rejection is retried once.
- A timeout maps to `DeliveryState.UNKNOWN` and is not retried.
- A repeated idempotency key makes one provider call.
- Reusing a key with changed content raises `IdempotencyConflict`.
- Invalid and external-recipient policy can be tested by the upstream application’s configured domain policy.
