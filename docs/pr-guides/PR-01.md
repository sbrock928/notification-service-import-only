# PR 1 — package scaffold and domain contracts

Commit:

```text
chore: scaffold import-only notification package
```

Goal: create an installable package that can be imported without starting a network client, worker, scheduler, or database connection.

Add:

```text
pyproject.toml
.gitignore
src/notification_service/__init__.py
src/notification_service/errors.py
src/notification_service/models.py
src/notification_service/provider.py
```

The complete code is the content of those files in this repository. The important public contract is:

```python
from notification_service import EmailNotification, Recipient

notification = EmailNotification(
    to=(Recipient("employee@contoso.com"),),
    subject="Job complete",
    text="The scheduled job completed.",
)
```

Review checklist:

- Models are immutable dataclasses.
- Recipient addresses, subject, attachment count/size, and idempotency keys are validated.
- `EmailProvider` is a Protocol and has no Microsoft-specific types.
- Importing `notification_service` performs no I/O.
- `pyproject.toml` has no FastAPI, Celery, Redis, SQLAlchemy, or Docker dependency.
