# PR 5 — explicitly configured Teams channel webhooks

Commit:

```text
feat(teams): add explicitly configured channel webhook provider
```

Goal: support Teams notifications only through named, preconfigured Power
Automate destinations. A caller supplies `ops-alerts`; it never supplies a
Teams URL or arbitrary channel ID.

Add a destination registry in the host application:

```python
teams_webhooks = {
    "ops-alerts": os.environ["PA_TEAMS_OPS_ALERTS_WEBHOOK"],
    "data-quality": os.environ["PA_TEAMS_DATA_QUALITY_WEBHOOK"],
}
```

Implement a provider that resolves the logical name, posts the supported text or
Adaptive Card payload, and returns the same accepted/failed/unknown result
semantics as email. Unknown destination names fail before any HTTP call.

Acceptance tests must cover destination allowlisting, webhook authentication,
429 handling, timeout-to-unknown behavior, and redaction of webhook URLs.
